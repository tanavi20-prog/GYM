# Adding Your Gym Background Image

## Step 1: Save the Image
1. Save your gym image (the "NO PAIN, NO GAIN" gym photo) as `gym-hero-bg.jpg`
2. Place it in: `E:\wamp64\www\gymmm\assets\images\gym-hero-bg.jpg`
3. Make sure the file is named exactly `gym-hero-bg.jpg` (replace the placeholder file)

## Step 2: Image Requirements
- **Format**: JPG or PNG (JPG recommended for smaller file size)
- **Size**: Recommended 1920x1080 or higher resolution
- **File size**: Keep under 2MB for faster loading

✅ Updated CSS to include the background image

✅ Enhanced hero text with shadows and gradients

## Step 4: Test Your Website
After saving the image, visit: `http://localhost/gymmm/home.php`

You should see:
- The gym image as the hero background
- "NO PAIN, NO GAIN" atmosphere
- Enhanced text readability with shadows
- Animated stat cards with gym-inspired styling
- Professional gradient overlays

## Alternative Image Paths
If you want to use a different image name, update this line in `assets/css/style.css`:
```css
url('../images/gym-hero-bg.jpg')
```
Change `gym-hero-bg.jpg` to your preferred filename.

## Troubleshooting
- If image doesn't show: Check file path and name
- If text is hard to read: The CSS already includes overlay gradients
- If image is too large: Compress it or use a smaller resolution
